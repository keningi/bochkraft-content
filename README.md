# BochKraft — контент лаунчера

Отсюда лаунчер BochKraft (by WMTech) берёт список модов, новости и хайлайты, а в Releases лежат установщики.

- `manifest.json` — сборка: моды скачиваются напрямую с Modrinth и CurseForge, сами моды здесь не хранятся
- `content.json` — новости, сплэши, подсказки, хайлайт дня
- `pack/` — настройки сборки, `media/` — видео
